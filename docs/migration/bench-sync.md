# Keeping the bench app in sync

## The problem this document exists for

`ucc_knowledge_chunk.py` was reported missing from the bench, with the whole
`sophia/doctype/` directory untracked on branch `develop`. The file was not
lost — it is committed here and present on `app-export`. What actually
happened is that **the bench copy is not tracking this repository**, so it
sits at whatever state it was last hand-copied to, and files added since
simply are not there.

That is a recurring failure, not a one-off. It was recorded once already in
`phase-2-plan.md` §8: the bench app directory was created by manual copy,
had no remote configured, and every round since has needed the same manual
step. The symptom changes each time; the cause does not.

## Confirm the diagnosis on the bench

```bash
cd ~/frappe-bench/apps/ucc_intelligence
git remote -v          # expect: nothing, or a remote that is not this repo
git branch --show-current
git log --oneline -3
git status --short | head
```

If `git remote -v` prints nothing, the directory has never pulled from
anywhere and untracked files are expected — including files that were never
copied across in the first place.

## Fix it once

```bash
cd ~/frappe-bench/apps/ucc_intelligence

# 1. Keep a copy of anything only on the bench, before anything else.
git status --short > /tmp/ucc-bench-local-state.txt
tar czf /tmp/ucc-bench-backup.tgz .

# 2. Point it at this repository's app-export branch, which contains exactly
#    the app payload (no docs/, no tools/, no legacy directories).
git remote add origin https://github.com/f3nd1/Intelligence-Dashboard-v2.git
git fetch origin app-export

# 3. Take the published state.
git checkout -B app-export origin/app-export

cd ~/frappe-bench
bench --site ucc-sms-v2.orb.local migrate
```

From then on, each round is:

```bash
cd ~/frappe-bench/apps/ucc_intelligence && git pull origin app-export
cd ~/frappe-bench && bench --site ucc-sms-v2.orb.local migrate && bench build --app ucc_intelligence
```

## Why `app-export` and not `main`

`main` has the app one directory deeper (`ucc_intelligence/ucc_intelligence/…`)
and carries `docs/`, `tools/`, `custom-html-block/` and `server-scripts/`.
`app-export` is generated by `git subtree split --prefix=ucc_intelligence`, so
its root IS the app package — the layout a bench expects.

## If a migrate ever aborts on a missing controller again

Frappe imports `<module>.doctype.<snake_name>.<snake_name>` for every DocType
it installs, and stops the whole run on the first failure — across every app
on the bench, not just this one. `tools/test_doctype_completeness.py` checks
that shape for all DocTypes in one pass, so run it before pushing:

```bash
python3 tools/test_doctype_completeness.py
```

To see immediately which DocType is incomplete on the bench itself:

```bash
cd ~/frappe-bench/apps/ucc_intelligence/ucc_intelligence/sophia/doctype
for d in */; do d=${d%/}; [ -f "$d/$d.py" ] || echo "MISSING CONTROLLER: $d"; done
```
