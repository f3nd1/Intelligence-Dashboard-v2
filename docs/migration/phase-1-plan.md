## 9. Rollback for this phase

Phase 1 only ever touches a non-production site and adds a new app — it cannot corrupt existing data
by construction, which is itself one of the §9 exit criteria to verify, not assume.

- **If install fails partway**: `bench --site <site> uninstall-app ucc_intelligence` (§9 exit
  criterion — "App uninstalls without corrupting unrelated data" is exactly this path, must be
  tested, not just trusted).
- **If uninstall itself is incomplete or leaves residue**: restore the site from its pre-Phase-1
  backup. A backup before `install-app` is a prerequisite for this phase to be safe to run at all —
  add `bench --site <site> backup` as the actual first command, before `bench new-app`, once a site is
  named.
- **Git rollback**: revert the commit(s) this phase produces on `main`/`claude/init-0ih6io`. No
  production code path references the new app yet (nothing in `custom-html-block/` or
  `server-scripts/` is edited), so a git revert alone is sufficient on the code side — the only
  stateful risk is the installed site itself, covered above.
- **No irreversible action is taken in this phase.** No legacy file is edited, moved, or deleted; no
  production site is touched (§9 "development or staging first" is a hard constraint, not a
  preference).

### 12.1 Health-check method — `ucc_intelligence/ucc_intelligence/api.py`

```python
import frappe


@frappe.whitelist()
def health_check():
	"""Confirm the app is installed and reachable. No business data, no auth bypass."""
	return {
		"ok": True,
		"app": "ucc_intelligence",
		"user": frappe.session.user,
	}
```

### 12.2 Test — `ucc_intelligence/ucc_intelligence/tests/test_api.py`

```python
import frappe
from frappe.tests.utils import FrappeTestCase

from ucc_intelligence.api import health_check


class TestHealthCheck(FrappeTestCase):
	def test_health_check_returns_ok(self):
		result = health_check()
		self.assertTrue(result["ok"])
		self.assertEqual(result["app"], "ucc_intelligence")
		self.assertEqual(result["user"], frappe.session.user)
```
