# Architecture Decision Records

CLAUDE.md §18 lists twelve decisions that must be recorded. Each ADR below
uses that section's own template.

A decision is recorded here when it was genuinely made — with the options
that were on the table and the reason one won. Decisions still open are
listed in `docs/migration/open-decisions.md` rather than being written up
as if they had been settled.
